# Участие в разработке

Спасибо за интерес к Codex Memory.

## Локальная проверка

Проект использует только стандартную библиотеку Python. Перед отправкой изменений выполните:

```powershell
python -m unittest discover -s tests -v
python -m compileall -q main.py codex_memory tests
```

## Требования к изменениям

- добавляйте тест для исправленного бага или нового поведения;
- не ослабляйте гарантии неизменности входной истории;
- не добавляйте сетевые вызовы, активные по умолчанию;
- не сохраняйте ответы LLM без структурной проверки;
- сохраняйте совместимость с Python 3.10+;
- избегайте обязательных зависимостей без явной необходимости.

## Приватные данные

Никогда не добавляйте в issue, commit или pull request:

- реальные истории переписки;
- содержимое `memory/` пользователя;
- API-ключи и `.env`;
- абсолютные пользовательские пути;
- локальные базы данных и логи.

Используйте короткие искусственные примеры. Перед commit проверяйте `git diff --staged`.
